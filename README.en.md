## About PI

You can use PI (Parameter Injection) in the scripts to specify various parameters using Lua expressions.\
PI has higher priority than the values specified by the trackbar.

You don't need to use it in most cases, but using PI allows for more flexible settings.\
Check the documentation of each script for the keys of the PI table.
