# Camera Frame.obj2

Draws a camera frame-like shape.

## PI

- `width`: Width in pixels
- `height`: Height in pixels
- `line_length`: Line length in pixels
- `line_thickness`: Line thickness in pixels
- `line_color`: Line color (`0xRRGGBB`)
- `size_specifier`: Size mode (1 = margin, 2 = absolute)
- `debug`: Debug mode
