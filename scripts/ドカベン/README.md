# ドカベン.anm2

[ドカベンの文字エフェクト](https://www.nicovideo.jp/watch/sm30220788)の移植。

## パラメーター

- 再生速度：アニメーションの速度（%）。100で通常速度、0でアニメーションを無効化します。
- 自動で倒れる：有効にすると、起き上がってから倒れる動きを繰り返します。無効にすると、起き上がった状態を維持します。
- 直立時間：倒れ始めるまでの待ち時間（フレーム数）。自動で倒れる場合のみ使用し、0では待たずに倒れ始めます。再生速度に応じて実際の待ち時間も変わります。
- Yオフセット：変形の基準位置を縦方向に調整します。
- コマ落ち：アニメーションを段階的に進め、カクカクした動きにします。

## PI

- `speed`：再生速度（数値、%）
- `auto_fall`：自動で倒れる（`true` / `false`）
- `upright`：直立時間（数値、0以上のフレーム数）
- `y_offset`：Yオフセット（数値）
- `drop_frame`：コマ落ち（`true` / `false`）
- `divisions_override`：横方向の分割数（1以上の整数）。省略時は画像の幅に応じて1～32分割します。値を増やすと変形時の歪みが目立ちにくくなりますが、描画負荷も増えます。
