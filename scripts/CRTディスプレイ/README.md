## PI

- `horizontal_blur`：水平ブラー
- `rgb_percent`：RGB効果の強さ（%）
- `pixel_size`：ピクセルサイズ
- `decay`：減衰
- `slowmotion`：スローモーション
- `use_progressive`：プログレッシブ走査を使用するか
