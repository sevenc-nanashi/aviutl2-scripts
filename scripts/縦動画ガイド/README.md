# 縦動画ガイド.obj2

ニコニコショートのUIで隠れる部分を表示するためのスクリプト。

> [!NOTE]
> デフォルトでは出力時に非表示になります。\
> 出力時にも表示したい場合は、「出力時にも表示」を有効にしてください。

## PI

- `device`：デバイス
  - `1`：iPhone 16（iOS 26）
  - `2`：iPad mini（iPadOS 26）
- `color`：色（`0xRRGGBB`）
- `show_forward`：ピン留め動画を表示するか
- `show_tags`：タグを表示するか
- `author_name_width`：投稿者名の幅（ピクセル単位）
- `side_line_width`：左右線の幅（ピクセル単位）
- `show_on_output`：出力時にも表示するか
- `layout`：レイアウト設定。`width`、`height`、`footer_height` などの値をテーブルで上書きできます。
