# Shorts Guide.obj2

Displays guides for areas hidden by the Niconico Shorts UI.

> [!NOTE]
> By default, this object is hidden during export.\
> Enable "Show on Export" if you also want it to appear in exported output.

## PI

- `device`: Device
  - `1`: iPhone 16 (iOS 26)
  - `2`: iPad mini (iPadOS 26)
- `color`: Color (`0xRRGGBB`)
- `show_forward`: Whether to show the pinned video area
- `show_tags`: Whether to show tags
- `author_name_width`: Author name width in pixels
- `side_line_width`: Side line width in pixels
- `show_on_output`: Whether to show during export
- `layout`: Layout settings. Values such as `width`, `height`, and `footer_height` can be overridden with a table.
