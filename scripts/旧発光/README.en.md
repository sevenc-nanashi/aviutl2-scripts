# Legacy Glow.anm2

Recreates AviUtl1 glow.

## PI

- `strength`: Strength
- `diffusion`: Diffusion
- `threshold`: Threshold
- `speed`: Diffusion speed
- `light_color`: Light color (`0xRRGGBB`, or `false` to use source chroma)
- `fixed_size`: Fixed size (`true` / `false`)
