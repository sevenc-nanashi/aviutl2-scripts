# CRT Display like.anm2

Apply a CRT display-like effect to a video.

## Acknowledgements

This script is based on [CRTディスプレイの再現 - ideoaves](https://ideoaves.github.io/blog/2025-12-10.html).
Thank you to hazuqu for granting permission for the port.

## PI

- `horizontal_blur`: Horizontal blur
- `rgb_percent`: RGB effect strength (%)
- `pixel_size`: Pixel size
- `decay`: Decay
- `slowmotion`: Slow motion
- `use_progressive`: Whether to use progressive scanning
